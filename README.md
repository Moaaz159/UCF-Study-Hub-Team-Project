# UCF Study Hub

UCF Study Hub is a full-stack web application designed to help UCF students upload, organize, search, and manage study materials in one place.

This project was developed as a team project for CIS 4004 using the LAMP stack. The application includes user authentication, study-note management, search features, user profiles, and a MySQL database.

## Features

- User registration and login/logout
- Secure password hashing
- Upload and manage study notes
- Search shared study materials
- Filter and organize notes
- Edit and delete uploaded notes
- User profile and personal notes pages
- JSON API endpoints
- AJAX/fetch communication between the frontend and backend
- MySQL database integration
- Cloud-hosted Linux deployment
